# Contributing

Thank you for taking an interest in GraphOWL.

## What this repository accepts

This repository is the public home of the product, **not its source code**, which is proprietary and not open to contributions. So:

- **Bug reports and feature requests** are welcome, as [issues](../../issues). Please use the templates and describe the situation before the solution.
- **Questions and ideas** belong in [Discussions](../../discussions).
- **Corrections to the documentation or this repository's text** are welcome as pull requests. By submitting one you agree that your contribution is licensed under the same Creative Commons Attribution 4.0 licence as the rest of the text here.
- **Security problems** must not be filed as issues. Follow [`SECURITY.md`](SECURITY.md).

Pull requests that change the product's behaviour cannot be accepted here, because the product's code is not in this repository.

## Libraries and examples

Client libraries and runnable examples will be published in their own repositories under the Apache-2.0 licence, each with its own contributing notes.

## Conduct

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
