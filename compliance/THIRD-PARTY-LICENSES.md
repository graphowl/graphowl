# Third-party licences

GraphOWL's server is built from 566 third-party Rust crates. Every one declares a licence, and the build is checked against a permissive-only allow-list (MIT, Apache-2.0, BSD, ISC, Unicode, Zlib); copyleft and source-available licences are rejected.

The machine-readable list is [`sbom.cdx.json`](sbom.cdx.json) (CycloneDX 1.5). It covers the server's Rust dependencies; the console's JavaScript dependencies are not yet included.
